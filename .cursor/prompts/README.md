# Cursor Prompts

Reusable prompts for common Forge development tasks. Reference these in Cursor chat using `@` syntax.

## Usage

In Cursor chat, type `@` and select the prompt file, then add your specific request:

```
@implement-feature.md add a --dry-run flag to the new command
```

```
@add-skill.md create a skill for running database seeds
```

```
@debug-scaffolding.md the .env.local file is missing WORKOS_CLIENT_ID
```

## Available Prompts

| Prompt | Use when... |
|--------|-------------|
| `implement-feature.md` | Building a new feature or command in Forge |
| `add-template.md` | Adding a new template file to scaffolded output |
| `add-skill.md` | Adding a new Claude Code skill to scaffolded projects |
| `debug-scaffolding.md` | Troubleshooting issues with scaffolded output |
